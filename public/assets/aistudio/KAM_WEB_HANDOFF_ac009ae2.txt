ملاحظات ربط حرجة للويب (Firebase JS SDK v10+):
1. تهيئة Firestore بالاسم المخصص (إلزامي):
   ```ts
   import { initializeApp } from "firebase/app";
   import { getAuth } from "firebase/auth";
   import { getFirestore } from "firebase/firestore";

   const app = initializeApp(firebaseConfig);
   export const auth = getAuth(app);
   export const db = getFirestore(app, FIRESTORE_DATABASE_ID);
   ```

1. وصف التطبيق والمستخدمون والأدوار
--------------------------------------------------------------------
اسم التطبيق: kAM (واسمه الظاهر للمستخدم: نجم الكارت)
الوصف: تطبيق إدارة فصول مدارس الأحد / الكنيسة (خدمة الأطفال) باللغة العربية (RTL)، يتيح للخدام وأمين الفصل تنظيم الأطفال داخل مجموعات/بلوكات للخدام، تسجيل الحضور الأسبوعي، منح كروت النقاط التحفيزية (7 كروت قياسية + كارت إضافي مخصص هو "كارت القمداء")، تتبع المحفوظات والتعليقات والافتقاد، عرض تقارير وتحليلات تفصيلية ولوحة الصدارة بتقويم الأسابيع (بداية الأسبوع يوم السبت) مع التقويم القبطي (تقويم الشهداء)، بالإضافة إلى نظام محادثات جماعية ومراسلات خاصة بين الخدام مع تقارير تلقائية ذكية.

أدوار المستخدمين والصلاحيات:
1. أمين الفصل الأساسي (Primary Admin — group.adminId):
   - إنشاء الفصل (الجروب) وحذفه وتغيير اسمه وصورته.
   - تعيين وإلغاء مساعدي الأمين (assistantAdminIds).
   - إدارة سياسات الفصل (السماح بالتراجع للخدام، منع تكرار الكارت أسبوعياً، الحد الأقصى الشهري للنقاط، إعدادات "كارت القمداء").
   - تجديد كود الدعوة اليومي، إنشاء/حذف البلوكات، حذف الأطفال، حظر/فك حظر الخدام، تعديل/حذف أي تسجيل حضور أو كارت لأي خادم.
2. مساعد الأمين (Assistant Admin — uid in group.assistantAdminIds):
   - يملك نفس صلاحيات الأمين الأساسي عبر البلوكات والأطفال والسياسات وكود الدعوة والحظر وتعديل/حذف التسجيلات، باستثناء أنه لا يستطيع تعديل قائمة assistantAdminIds أو حظر الأمين الأساسي أو حذف الجروب.
3. الخادم (Servant — uid in group.memberUids):
   - رؤية جميع الأطفال والبلوكات والأحداث في الفصل.
   - إضافة وتعديل بيانات الأطفال وصورهم ونقلهم بين البلوكات، منح الكروت، التراجع عن الكروت التي سجلها بنفسه فقط (عند تفعيل allowServantUndo).
   - تسجيل الحضور والافتقاد والمحفوظات والتعليقات، تعديل اسمه في البلوك المخصص له، المشاركة في الشات الجماعي والرسائل الخاصة، وإدارة ملفه الشخصي وتفضيلات العرض الخاصة به.

2. كل الشاشات والمميزات (Screens & Features) بالتفصيل
--------------------------------------------------------------------
يتكون التطبيق من شاشات الدخول والإعداد الأولي + 4 تبويبات رئيسية في التنقل (الرئيسية، الرسائل، المجموعة، الإعدادات) + شاشات فرعية/نوافذ منبثقة:

أ) شاشة تسجيل الدخول (SignInScreen):
- تسجيل دخول عبر Google Sign-In فقط (لا يوجد Anonymous Auth ولا Email/Password).
- عند نجاح الدخول:
  1. يتم إنشاء أو تحديث users/{uid}.
  2. يتم تسجيل/تحديث فهرس البريد الإلكتروني في emailDirectory/em_{sha256_40} للبحث عن الخدام بالإيميل لبدء محادثة خاصة.
  3. إذا لم يكن لدى المستخدم groupId نشط، يتم توجيهه لشاشة GroupOnboarding.

ب) شاشة إنشاء أو الانضمام لمجموعة (GroupOnboardingScreen):
- إنشاء فصل جديد: إدخال اسم الفصل -> توليد inviteCode (8 أحرف تبدأ بـ KAM مثل KAM4X9P2) وتعيينه كـ Document ID للمجموعة + توليد dailyInviteToken عشوائي (4 أحرف) صالح 24 ساعة + إضافة الأمين في memberUids و members/{uid} وتحديث users/{uid}.
- الانضمام لفصل موجود: إدخال كود الدعوة المركّب <inviteCode>-<dailyToken> -> جلب groups/{inviteCode} والتحقق من:
  - أن المستخدم غير موجود في bannedUids.
  - أن dailyInviteToken مطابق وأن الكود لم تنتهِ صلاحيته (24 ساعة من inviteCodeUpdatedAtMillis).
  - ثم إضافة uid إلى memberUids وإنشاء groups/{groupId}/members/{uid} وتحديث users/{uid} (groupId و joinedGroupIds).

ج) الشاشة الرئيسية (HomeScreen):
- الهيدر العلوي:
  - اسم الفصل النشط مع إمكانية التبديل بين الفصول المنضم إليها (joinedGroupIds).
  - منتقي الشهر/الأسبوع الحالي (بتقويم السبت + التقويم القبطي).
  - زر تحديث/مزامنة شاملة مع السحابة (في الموبايل: Pull-to-refresh + ضغطتين على زر البيت؛ والضغط مرة واحدة على زر البيت من أي شاشة فرعية يعيد للرئيسية).
- شريط البحث العربي الفوري:
  - بحث بالاسم أو رقم الطفل (#studentNumber) مع تطبيع الحروف العربية (إزالة التشكيل والمد، توحيد أ/إ/آ -> ا، ة -> ه، ى -> ي) و Debounce خفيف (~180ms) لمنع التعليق.
- شريط الإجراءات السريعة:
  - فتح التحضير الذكي بالسحب (SmartAttendance).
  - فتح الافتقاد الذكي بالسحب (VisitationSwipe).
  - فتح التقارير ولوحة الصدارة (Reports / Leaderboard — أيقونة الكأس).
  - إضافة طفل جديد / استيراد جماعي ذكي (لصق قائمة أسماء دفعة واحدة مع كشف المكررات وخيار الدمج أو الاحتفاظ).
- تنبيهات تكرار الكروت (DuplicateCardAlerts):
  - تنبيه يظهر إذا حصل طفل على نفس الكارت مرتين في نفس الأسبوع من خادمين مختلفين، مع إمكانية التراجع أو إرسال تنبيه للشات.
- قائمة البلوكات والأطفال (ServantBlocks + قسم "بدون بلوك"):
  - كل بلوك له رأس بتصميم شبيه بواتساب (لون البلوك، صورة الخادم المسؤول، نقطة خضراء أونلاين إذا كان lastSeenAt أقل من 3 دقائق، أزرار اتصال/واتساب إذا لم يكن الرقم مخفياً، زر طي/إظهار البلوك يُحفظ في users/{uid}.collapsedBlockIds).
  - كل صف طفل يعرض:
    - صورة الطفل (Lazy-loaded من groups/{groupId}/avatars/{studentId} أو الحروف الأولى avatarInitials).
    - رقم الطفل #studentNumber واسم الطفل.
    - لمبة الحضور الصغيرة بجانب الاسم للأسبوع المختار: خضراء = PRESENT، حمراء = ABSENT، كهرمانية = ISSUE، ومخفية/رمادية إذا لم يُسجل بعد.
    - مجموع نقاط الطفل في الشهر الحالي.
    - أزرار منح الكروت السريعة (الكروت المفعّلة للمستخدم في enabledCards + CUSTOM_ELDER إذا فعّله الأمين): ضغطة لمنح الكارت، وضغطة أخرى للتراجع (إذا مسموح).
- ملف الطفل الكامل (ChildProfileSheet):
  - تعديل بيانات الطفل: الاسم + الرقم + اختيار البلوك ("بدون بلوك" أو أي بلوك موجود) مع الحفاظ على الترتيب.
  - معرض صور الطفل (رفع/حذف/تبديل الصورة الأساسية — تُحفظ مضغوطة Base64 في avatars/{studentId}).
  - تبويبات/أقسام: المحفوظات (MEMORIZATION + تحديث lastMemorizedText)، التعليقات (COMMENT)، سجل الافتقاد (VISITATION)، سجل الكروت والنقاط (مع التراجع).
  - إرسال إشعار منسّق خاص بالطفل إلى شات المجموعة.

د) شاشة التحضير الذكي بالسحب (SmartAttendanceScreen):
- اختيار وضع الجلسة قبل/أثناء البدء:
  - وضع الحضور (ATTENDANCE_ONLY)
  - أو وضع كارت محدد (مثل كارت الهدوء، المشاركة، التسبحة، الذهب، المحفوظات، الاعتراف، أو كارت القمداء CUSTOM_ELDER).
- عرض الأطفال كبطاقات بصورة كبيرة (Swipe Cards أو أزرار سريعة على الويب):
  - يمين: حضر / أخذ الكارت (PRESENT).
  - يسار: غائب / لم يأخذ الكارت (ABSENT / NO_CARD).
  - أسفل: عمل مشكلة مع كتابة ملاحظة (ISSUE).
  - تراجع (Undo Stack): التراجع خطوة بخطوة.
- الحفظ والمزامنة:
  - حفظ سجل الحضور في groups/{groupId}/attendance/{weekKey}_{studentId}.
  - عند اختيار وضع كارت: يتم أيضاً منح/حذف cardEvent المقابل وتحديث monthlyBalances.
- إرسال التقرير المجمع للشات ([ATTENDANCE_V3] + منطق الاختلافات Cross-Servant Diff):
  - قبل الإرسال، يبحث التطبيق عن أقدم تقرير أساسي غير-Diff من نفس الأسبوع (weekKey) ونفس نوع التقرير (reportTypeKey) أرسله خادم آخر:
    - إذا لم يوجد -> يرسل تقرير [ATTENDANCE_V3] كامل.
    - إذا وُجد -> يقارن نتائج الخادم الثاني بتقرير الخادم الأول الثابت:
      - إذا لم توجد أي اختلافات -> لا يرسل رسالة جديدة ويعرض تنبيهاً (Toast): "التقرير مطابق تماماً لتقرير الخادم الأول".
      - إذا وجدت اختلافات -> يرسل رسالة [ATTENDANCE_V3] تحتوي سطر DIFF|<اسم الخادم الأول> وأسطر D|... للاختلافات فقط!

هـ) شاشة الافتقاد الذكي بالسحب (VisitationSwipeScreen):

ز) شاشة الرسائل والمحادثات (MessagesScreen):

  - حذف ناعم لرسائلك فقط (isDeleted: true, text: "تم حذف الرسالة", mediaBase64: "").
  - إعادة توجيه رسالة (forwardedFromName).

     - في الذيل: تصنيف الغير مفتقدين/المتابعة حسب اسم البلوك + عددهم + أرقامهم، ثم المجموع الكلي.

     - هيدر ملون واضح يحدد نوع التقرير بدقة (مثلاً "📋 تقرير الحضور" أو "🤫 تقرير كارت الهدوء" أو "🏅 تقرير كارت القمداء").
     - شبكة من 3 أعمدة بصورة ورقم واسم للغائبين / من لم يأخذوا الكارت / أصحاب المشاكل.
     - شريط مدمج بخط صغير بأسماء الحاضرين / من أخذوا الكارت.
     - في الذيل: تصنيف الغائبين/المشاكل حسب اسم البلوك + عددهم + أرقامهم، ثم المجموع الكلي.
     - حالة تقرير الاختلافات (DIFF|): هيدر "🔄 اختلافات تقرير ..." يعرض مقارنة حالة الخادم الأول مقابل الخادم الثاني لكل طفل مختلف فقط.
  3. بطاقات الإشعارات الفردية للطفل (notificationCategory): ملونة حسب الفئة (CONFLICT برتقالي، ABSENT أحمر، COMMENT سماوي، VISITATION بنفسجي، MEMORIZATION فيروزي، CARD أخضر، SYSTEM نيلي).

3. قاعدة البيانات (Cloud Firestore Schema)
--------------------------------------------------------------------
النوع: Cloud Firestore
معرّف القاعدة (Database ID): ai-studio-android-69ef64c0-fb21-4e5d-8c5b-9e185b0c9dc1
ملاحظة حاسمة: قواعد الأمان تطبق hasOnly(...) صارم على كل Collection — ممنوع إرسال أي حقل غير مذكور أدناه وإلا سترفض Firestore العملية فوراً (PERMISSION_DENIED).

1) users/{userId} (ملف المستخدم الشخصي — معزول تماماً للمالك فقط)

    // Group membership lookup on the parent /groups/{groupId} document.
    // Every member whose UID is in groups/{groupId}.memberUids (or adminId) has full shared access
    // to all students, blocks, cardEvents, monthlyBalances, and invitations in that group—
    // even if a child or block was created before a new servant joined!
    function isGroupMember(groupId) {
      return isSignedIn() &&
        exists(/databases/$(database)/documents/groups/$(groupId)) &&
        (
          uid() in get(/databases/$(database)/documents/groups/$(groupId)).data.memberUids ||
          get(/databases/$(database)/documents/groups/$(groupId)).data.adminId == uid() ||
          (
            'assistantAdminIds' in get(/databases/$(database)/documents/groups/$(groupId)).data &&
            uid() in get(/databases/$(database)/documents/groups/$(groupId)).data.assistantAdminIds
          )
        );
    }

        data.eventsCount is int && data.eventsCount >= 0 && data.eventsCount <= 10000 &&
        isNonEmptyString(data.lastUpdatedByUid, 64) &&
        (!('memberUids' in data) || isBoundedStringList(data.memberUids, 1, 50)) &&
        data.createdAt is timestamp &&
        data.updatedAt is timestamp;
    }

    function isValidGroupMemberProfile(data, groupId, memberUid) {
      return data.keys().hasAll([
          'uid', 'groupId', 'displayName', 'phoneVerified', 'createdAt', 'updatedAt'
        ]) &&
        data.keys().hasOnly([
          'uid', 'groupId', 'displayName', 'email', 'phone', 'primaryPhone', 'secondaryPhone',
          'phoneVerified', 'showPhone', 'phoneHidden', 'avatar', 'hasAvatar',
          'avatarHash', 'avatarBase64', 'memberUids', 'lastSeenAt', 'createdAt', 'updatedAt'
        ]) &&
        data.uid == memberUid &&
        data.groupId == groupId &&
        isNonEmptyString(data.uid, 64) &&
        isNonEmptyString(data.displayName, 100) &&
        (!('email' in data) || isOptionalString(data.email, 150)) &&
        (!('phone' in data) || isOptionalString(data.phone, 24)) &&
        (!('primaryPhone' in data) || isOptionalString(data.primaryPhone, 24)) &&
        (!('secondaryPhone' in data) || isOptionalString(data.secondaryPhone, 24)) &&
        data.phoneVerified is bool &&
        data.phoneVerified == false &&
        (!('showPhone' in data) || data.showPhone is bool) &&
        (!('phoneHidden' in data) || data.phoneHidden is bool) &&
        (!('avatar' in data) || isOptionalString(data.avatar, 360000)) &&
        (!('hasAvatar' in data) || data.hasAvatar is bool) &&
        (!('avatarHash' in data) || isOptionalString(data.avatarHash, 64)) &&
        (!('avatarBase64' in data) || isOptionalString(data.avatarBase64, 360000)) &&
        (!('memberUids' in data) || isBoundedStringList(data.memberUids, 1, 50)) &&
        (!('lastSeenAt' in data) || data.lastSeenAt is timestamp) &&
        data.createdAt is timestamp &&
        data.updatedAt is timestamp;
    }

    function isValidChatMessagePayloadByType(data) {
      return (
        (data.type == 'TEXT' &&
          data.text is string && data.text.size() > 0 && data.text.size() <= 1000 &&
          (!('mediaBase64' in data) || data.mediaBase64 == '')) ||
        (data.type == 'SYSTEM' &&
          data.text is string && data.text.size() > 0 && data.text.size() <= 4000 &&
          (!('mediaBase64' in data) || data.mediaBase64 == '')) ||
        (data.type == 'IMAGE' &&
          data.text is string && data.text.size() > 0 && data.text.size() <= 1000 &&
          'mediaBase64' in data && data.mediaBase64 is string &&
          data.mediaBase64.size() > 0 && data.mediaBase64.size() <= 460000 &&
          (!('mediaUrl' in data) || isOptionalString(data.mediaUrl, 500)) &&
          (!('mediaMimeType' in data) || isOptionalString(data.mediaMimeType, 60)) &&
          (!('imageWidth' in data) || (data.imageWidth is int && data.imageWidth >= 0 && data.imageWidth <= 1600)) &&
          (!('imageHeight' in data) || (data.imageHeight is int && data.imageHeight >= 0 && data.imageHeight <= 1600))) ||
        (data.type == 'AUDIO' &&
          data.text is string && data.text.size() > 0 && data.text.size() <= 1000 &&
          'mediaBase64' in data && data.mediaBase64 is string &&
          data.mediaBase64.size() > 0 && data.mediaBase64.size() <= 100000 &&
          (!('mediaUrl' in data) || isOptionalString(data.mediaUrl, 500)) &&
          (!('mediaMimeType' in data) || isOptionalString(data.mediaMimeType, 60)) &&
          'audioDurationSec' in data && data.audioDurationSec is int &&
          data.audioDurationSec >= 1 && data.audioDurationSec <= 30)
      );
    }

    function isValidGroupChatMeta(data, groupId) {
      return data.keys().hasAll([
          'groupId', 'memberUids', 'updatedAt'
        ]) &&
        data.keys().hasOnly([
          'groupId', 'lastMessageId', 'lastMessageText', 'lastMessageType',
          'lastMessageSenderUid', 'lastMessageSenderName', 'lastMessageAt',
          'totalMessagesCount', 'memberUids', 'updatedAt'
        ]) &&
        data.groupId == groupId &&
        isBoundedStringList(data.memberUids, 1, 50) &&
        uid() in data.memberUids &&
        (!('lastMessageId' in data) || isOptionalString(data.lastMessageId, 120)) &&
        (!('lastMessageText' in data) || isOptionalString(data.lastMessageText, 1000)) &&
        (!('lastMessageType' in data) || data.lastMessageType in ['TEXT', 'IMAGE', 'AUDIO', 'SYSTEM']) &&
        (!('lastMessageSenderUid' in data) || isOptionalString(data.lastMessageSenderUid, 64)) &&
        (!('lastMessageSenderName' in data) || isOptionalString(data.lastMessageSenderName, 100)) &&
        (!('lastMessageAt' in data) || data.lastMessageAt is timestamp) &&
        (!('totalMessagesCount' in data) || (data.totalMessagesCount is int && data.totalMessagesCount >= 0)) &&
        data.updatedAt is timestamp;
    }

    function isValidGroupChatMessageCreate(data, groupId) {
      return data.keys().hasAll([
          'groupId', 'senderUid', 'senderName', 'type', 'text',
          'isDeleted', 'memberUids', 'createdAt', 'updatedAt'
        ]) &&
        data.keys().hasOnly([
          'chatId', 'groupId', 'senderUid', 'senderName', 'type', 'text',
          'mediaBase64', 'mediaUrl', 'mediaMimeType', 'imageWidth', 'imageHeight', 'audioDurationSec',
          'notificationCategory', 'childId', 'childName', 'childBlockName', 'forwardedFromName',
          'isDeleted', 'memberUids', 'createdAt', 'updatedAt'
        ]) &&
        data.groupId == groupId &&
        data.senderUid == uid() &&
        isNonEmptyString(data.senderName, 100) &&
        data.type in ['TEXT', 'IMAGE', 'AUDIO', 'SYSTEM'] &&
        isValidChatMessagePayloadByType(data) &&
        (!('notificationCategory' in data) || isOptionalString(data.notificationCategory, 40)) &&
        (!('childId' in data) || isOptionalString(data.childId, 80)) &&
        (!('childName' in data) || isOptionalString(data.childName, 100)) &&
        (!('childBlockName' in data) || isOptionalString(data.childBlockName, 100)) &&
        (!('forwardedFromName' in data) || isOptionalString(data.forwardedFromName, 100)) &&
        data.isDeleted == false &&
        isBoundedStringList(data.memberUids, 1, 50) &&
        uid() in data.memberUids &&
        data.createdAt is timestamp &&
        data.updatedAt is timestamp;
    }

    function isValidChatMessageSoftDelete(newData, oldData) {
      return oldData.senderUid == uid() &&
        newData.senderUid == oldData.senderUid &&
        (!('groupId' in oldData) || newData.groupId == oldData.groupId) &&
        newData.createdAt == oldData.createdAt &&
        newData.isDeleted == true &&
        newData.text == 'تم حذف الرسالة' &&
        (!('mediaBase64' in newData) || newData.mediaBase64 == '') &&
        newData.updatedAt is timestamp;
    }

    function isValidLiveSystemReportUpdate(newData, oldData) {
      return oldData.senderUid == uid() &&
        oldData.type == 'SYSTEM' &&
        oldData.isDeleted == false &&
        newData.senderUid == oldData.senderUid &&
        newData.senderName == oldData.senderName &&
        newData.type == 'SYSTEM' &&
        newData.isDeleted == false &&
        (!('groupId' in oldData) || newData.groupId == oldData.groupId) &&
        newData.createdAt == oldData.createdAt &&
        newData.diff(oldData).affectedKeys().hasOnly(['text', 'updatedAt']) &&
        newData.text is string && newData.text.size() > 0 && newData.text.size() <= 4000 &&
        newData.updatedAt is timestamp;
    }

    function isValidDmChatMeta(data, chatId) {
      return data.keys().hasAll([
          'participants', 'updatedAt'
        ]) &&
        data.keys().hasOnly([
          'chatId', 'groupId', 'participants', 'participantNames',
          'lastMessageId', 'lastMessageText', 'lastMessageType',
          'lastMessageSenderUid', 'lastMessageSenderName', 'lastMessageAt',
          'totalMessagesCount', 'createdAt', 'updatedAt'
        ]) &&
        (!('chatId' in data) || data.chatId == chatId) &&
        (!('groupId' in data) || isOptionalString(data.groupId, 40)) &&
        isBoundedStringList(data.participants, 2, 2) &&
        uid() in data.participants &&
        (!('participantNames' in data) || data.participantNames is map) &&
        (!('lastMessageId' in data) || isOptionalString(data.lastMessageId, 120)) &&
        (!('lastMessageText' in data) || isOptionalString(data.lastMessageText, 1000)) &&
        (!('lastMessageType' in data) || data.lastMessageType in ['TEXT', 'IMAGE', 'AUDIO', 'SYSTEM']) &&
        (!('lastMessageSenderUid' in data) || isOptionalString(data.lastMessageSenderUid, 64)) &&
        (!('lastMessageSenderName' in data) || isOptionalString(data.lastMessageSenderName, 100)) &&
        (!('lastMessageAt' in data) || data.lastMessageAt is timestamp) &&
        (!('totalMessagesCount' in data) || (data.totalMessagesCount is int && data.totalMessagesCount >= 0)) &&
        (!('createdAt' in data) || data.createdAt is timestamp) &&
        data.updatedAt is timestamp;
    }

    function isValidDmChatMessageCreate(data, chatId) {
      return data.keys().hasAll([
          'senderUid', 'senderName', 'type', 'text',
          'isDeleted', 'participants', 'createdAt', 'updatedAt'
        ]) &&
        data.keys().hasOnly([
          'chatId', 'groupId', 'senderUid', 'senderName', 'type', 'text',
          'mediaBase64', 'mediaUrl', 'mediaMimeType', 'imageWidth', 'imageHeight', 'audioDurationSec',
          'notificationCategory', 'childId', 'childName', 'childBlockName', 'forwardedFromName',
          'isDeleted', 'participants', 'createdAt', 'updatedAt'
        ]) &&
        (!('chatId' in data) || data.chatId == chatId) &&
        (!('groupId' in data) || isOptionalString(data.groupId, 40)) &&
        data.senderUid == uid() &&
        isNonEmptyString(data.senderName, 100) &&
        data.type in ['TEXT', 'IMAGE', 'AUDIO', 'SYSTEM'] &&
        isValidChatMessagePayloadByType(data) &&
        (!('notificationCategory' in data) || isOptionalString(data.notificationCategory, 40)) &&
        (!('childId' in data) || isOptionalString(data.childId, 80)) &&
        (!('childName' in data) || isOptionalString(data.childName, 100)) &&
        (!('childBlockName' in data) || isOptionalString(data.childBlockName, 100)) &&
        (!('forwardedFromName' in data) || isOptionalString(data.forwardedFromName, 100)) &&
        data.isDeleted == false &&
        isBoundedStringList(data.participants, 2, 2) &&
        uid() in data.participants &&
        data.createdAt is timestamp &&
        data.updatedAt is timestamp;
    }

    function isValidAttendanceRecord(data, groupId, attendanceId) {
      return data.keys().hasAll([
          'studentId', 'studentName', 'status', 'weekKey',
          'servantId', 'servantName', 'note', 'createdAt', 'memberUids'
        ]) &&
        data.keys().hasOnly([
          'groupId', 'studentId', 'studentName', 'status', 'weekKey',
          'servantId', 'servantName', 'note', 'memberUids', 'createdAt', 'updatedAt'
        ]) &&
        (!('groupId' in data) || data.groupId == groupId) &&
        attendanceId == (data.weekKey + '_' + data.studentId) &&
        isNonEmptyString(data.studentId, 80) &&
        isNonEmptyString(data.studentName, 100) &&
        data.status in ['PRESENT', 'ABSENT', 'ISSUE'] &&
        isNonEmptyString(data.weekKey, 20) &&
        isNonEmptyString(data.servantId, 64) &&
        isNonEmptyString(data.servantName, 80) &&
        isOptionalString(data.note, 200) &&
        isBoundedStringList(data.memberUids, 1, 50) &&
        data.createdAt is timestamp &&
        (!('updatedAt' in data) || data.updatedAt is timestamp);
    }

    function isValidChildNote(data, groupId) {
      return data.keys().hasAll([
          'groupId', 'studentId', 'studentName', 'type', 'text',
          'authorUid', 'authorName', 'createdAt', 'updatedAt'
        ]) &&
        data.keys().hasOnly([
          'groupId', 'studentId', 'studentName', 'type', 'text',
          'status', 'authorUid', 'authorName', 'clientCreatedAtMillis',
          'memberUids', 'createdAt', 'updatedAt'
        ]) &&
        data.groupId == groupId &&
        isNonEmptyString(data.studentId, 80) &&
        isNonEmptyString(data.studentName, 100) &&
        data.type in ['COMMENT', 'MEMORIZATION', 'VISITATION'] &&
        isNonEmptyString(data.text, 500) &&
        (!('status' in data) || isOptionalString(data.status, 30)) &&
        data.authorUid == uid() &&
        isNonEmptyString(data.authorName, 80) &&
        (!('clientCreatedAtMillis' in data) || (data.clientCreatedAtMillis is int && data.clientCreatedAtMillis >= 0)) &&
        (!('memberUids' in data) || isBoundedStringList(data.memberUids, 1, 50)) &&
        data.createdAt is timestamp &&
        data.updatedAt is timestamp;
    }

    // ===============================================================
    // Collection Rules
    // ===============================================================

    // 1. User Profiles (Strict Owner Isolation for PII & Personal Preferences)
    match /users/{userId} {
      allow get: if isDocOwner(userId);
      allow list: if false;
      allow create: if isDocOwner(userId) && isValidUserProfile(incoming());
      allow update: if isDocOwner(userId) &&
        isValidUserProfile(incoming()) &&
        (!('createdAt' in existing()) || incoming().createdAt == existing().createdAt);
      allow delete: if isDocOwner(userId);
    }

    // 1b. Email Lookup Directory (exact get only; no list scraping)
    match /emailDirectory/{emailKey} {
      allow get: if isSignedIn() && isValidId(emailKey);
      allow list: if false;
      allow create: if isSignedIn() && isValidId(emailKey) && isValidEmailDirectoryEntry(incoming());
      allow update: if isSignedIn() && isValidId(emailKey) &&
        existing().uid == uid() &&
        isValidEmailDirectoryEntry(incoming());
      allow delete: if isSignedIn() && existing().uid == uid();
    }

    // 2. Groups (Admin + up to 6 Servants)
    match /groups/{groupId} {
      // Any signed-in user who knows the exact inviteCode (document ID) can fetch the group to join it.
      allow get: if isSignedIn();
      // Listing groups is only allowed for groups where the user is already a member.
      allow list: if isSignedIn() && uid() in existing().memberUids;

      allow create: if isSignedIn() &&
        incoming().adminId == uid() &&
        'createdAt' in incoming() &&
        isValidGroup(incoming(), groupId);

      // Primary Admin can update all fields including assistantAdminIds;
      // Assistant Admins can update policies, invite tokens, bans, avatar, and memberUids (except changing adminId/assistantAdminIds or banning primary admin);
      // Regular members can update non-policy fields (e.g. avatar or leaving) without touching policies/bans/assistants;
      // Joining non-banned servants can append ONLY their own UID to memberUids.
      allow update: if isSignedIn() &&
        isValidGroup(incoming(), groupId) &&
        incoming().adminId == existing().adminId &&
        incoming().inviteCode == existing().inviteCode &&
        (!('createdAt' in existing()) || incoming().createdAt == existing().createdAt) &&
        (
          existing().adminId == uid() ||
          (
            'assistantAdminIds' in existing() &&
            uid() in existing().assistantAdminIds &&
            !incoming().diff(existing()).affectedKeys().hasAny(['assistantAdminIds']) &&
            !('bannedUids' in incoming() && existing().adminId in incoming().bannedUids)
          ) ||
          (
            !incoming().diff(existing()).affectedKeys().hasAny([
              'assistantAdminIds', 'bannedUids', 'bannedServantEntries',
              'dailyInviteToken', 'inviteCodeUpdatedAtMillis', 'name',
              'allowServantUndo', 'enforceWeeklyCardLimit', 'maxMonthlyPoints',
              'attendanceIsCardOnly', 'showLeaderboard', 'autoStudentNumber',
              'customCardEnabled', 'customCardName', 'customCardPoints',
              'customCardIcon', 'customCardColorKey', 'customCardFrequency'
            ]) &&
            (
              uid() in existing().memberUids ||
              (
                uid() in incoming().memberUids &&
                !('bannedUids' in existing() && uid() in existing().bannedUids) &&
                incoming().memberUids.size() == existing().memberUids.size() + 1 &&
                incoming().memberUids.hasAll(existing().memberUids)
              )
            )
          )
        );

      allow delete: if isSignedIn() && existing().adminId == uid();

      // 2a. Group Invitations
      match /invitations/{invitationId} {
        allow get, list: if isGroupMember(groupId);
        allow create: if isGroupAdmin(groupId) && isValidInvitation(incoming(), groupId);
        allow update: if isGroupMember(groupId) &&
          isValidInvitation(incoming(), groupId) &&
          incoming().groupId == existing().groupId &&
          incoming().adminId == existing().adminId &&
          incoming().createdAt == existing().createdAt;
        allow delete: if isGroupAdmin(groupId);
      }

      // 2b. Servant Blocks
      // Read/List: Any member of the group (queried by groupId).
      // Create & Delete: Strictly Group Admin ONLY.
      // Update: Group Admin OR assigned servant updating only their own servantName / claiming unassigned block.
      match /blocks/{blockId} {
        allow get, list: if isGroupMember(groupId);
        allow create: if isGroupAdmin(groupId) && isValidServantBlock(incoming(), groupId);
        allow update: if isValidServantBlock(incoming(), groupId) &&
          incoming().groupId == existing().groupId &&
          incoming().createdAt == existing().createdAt &&
          (
            isGroupAdmin(groupId) ||
            (
              isGroupMember(groupId) &&
              existing().servantId == uid() &&
              incoming().servantId == existing().servantId &&
              incoming().colorHex == existing().colorHex &&
              incoming().sortOrder == existing().sortOrder
            )
          );
        allow delete: if isGroupAdmin(groupId);
      }

      // 2c. Students (Children)
      // Read/List: Any member of the group (queried by groupId — no stale memberUids array dependency!).
      // Create/Update: Any member of the group (supports adding, editing, moving blocks, and fractional position).
      // Delete: Strictly Group Admin ONLY.
      match /students/{studentId} {
        allow get, list: if isGroupMember(groupId);
        allow create: if isGroupMember(groupId) &&
          isValidStudent(incoming(), groupId);
        allow update: if isGroupMember(groupId) &&
          isValidStudent(incoming(), groupId) &&
          incoming().groupId == existing().groupId &&
          incoming().createdAt == existing().createdAt;
        allow delete: if isGroupAdmin(groupId);
      }

      // 2d. Card Events (7 Approved Cards Audit Log)
      // Read/List: Any member of the group.
      // Create/Update: Any member of the group.
      // Delete (Undo): Group Admin OR Servant who recorded the event when allowServantUndo is enabled.
      match /cardEvents/{eventId} {
        allow get, list: if isGroupMember(groupId);
        allow create: if isGroupMember(groupId) &&
          incoming().servantId == uid() &&
          isValidCardEvent(incoming(), groupId);
        allow update: if isGroupMember(groupId) &&
          isValidCardEvent(incoming(), groupId) &&
          incoming().groupId == existing().groupId &&
          incoming().cardType == existing().cardType &&
          incoming().points == existing().points;
        allow delete: if isGroupAdmin(groupId) ||
          (
            isGroupMember(groupId) &&
            existing().servantId == uid() &&
            groupAllowsServantUndo(groupId)
          );
      }

      // 2e. Monthly Balances
      match /monthlyBalances/{balanceId} {
        allow get, list: if isGroupMember(groupId);
        allow create: if isGroupMember(groupId) &&
          isValidMonthlyBalance(incoming(), groupId);
        allow update: if isGroupMember(groupId) &&
          isValidMonthlyBalance(incoming(), groupId) &&
          incoming().groupId == existing().groupId &&
          incoming().studentId == existing().studentId &&
          incoming().monthKey == existing().monthKey;
        allow delete: if isGroupAdmin(groupId);
      }

      // 2f. Student Avatars (Lazy-loaded separate collection per child)
      match /avatars/{studentId} {
        allow get, list: if isGroupMember(groupId);
        allow create: if isGroupMember(groupId) &&
          isValidStudentAvatar(incoming(), groupId, studentId);
        allow update: if isGroupMember(groupId) &&
          isValidStudentAvatar(incoming(), groupId, studentId) &&
          incoming().groupId == existing().groupId &&
          incoming().studentId == existing().studentId;
        allow delete: if isGroupMember(groupId);
      }

      // 2g. Group Servant Member Profiles (WhatsApp-style header profile above each block)
      // Read/List: Strictly members of the same group ONLY.
      // Create/Update: Strictly the servant who owns `memberUid` (`isDocOwner(memberUid)`) AND is a member of the group.
      // Delete: The servant themselves OR the Group Admin.
      match /members/{memberUid} {
        allow get, list: if isGroupMember(groupId);
        allow create: if isGroupMember(groupId) &&
          isDocOwner(memberUid) &&
          isValidGroupMemberProfile(incoming(), groupId, memberUid);
        allow update: if isGroupMember(groupId) &&
          isDocOwner(memberUid) &&
          isValidGroupMemberProfile(incoming(), groupId, memberUid) &&
          incoming().uid == existing().uid &&
          incoming().groupId == existing().groupId;
        allow delete: if isDocOwner(memberUid) || isGroupAdmin(groupId);
      }

      // 2h. Group Chat Metadata (groups/{groupId}/chatMeta/main)
      // Verified directly via `memberUids` on the document without requiring `get()`.
      match /chatMeta/{metaId} {
        allow get, list: if isSignedIn() && (
          resource == null ||
          ('memberUids' in existing() && uid() in existing().memberUids) ||
          isGroupMember(groupId)
        );
        allow create, update: if isSignedIn() && isValidGroupChatMeta(incoming(), groupId);
        allow delete: if false;
      }

      // 2i. Group Chat Messages (groups/{groupId}/messages/{messageId})
      // Verified directly via `memberUids` on the document without requiring `get()`.
      match /messages/{messageId} {
        allow get, list: if isSignedIn() && (
          ('memberUids' in existing() && uid() in existing().memberUids) ||
          isGroupMember(groupId)
        );
        allow create: if isSignedIn() && isValidGroupChatMessageCreate(incoming(), groupId);
        allow update: if isSignedIn() &&
          (('memberUids' in existing() && uid() in existing().memberUids) || isGroupMember(groupId)) &&
          (
            isValidChatMessageSoftDelete(incoming(), existing()) ||
            isValidLiveSystemReportUpdate(incoming(), existing())
          );
        allow delete: if false;
      }

      // 2j. Smart Swipe Attendance Records (groups/{groupId}/attendance/{weekKey}_{studentId})
      // Read/List: Group members (via memberUids or group membership).
      // Create: Any group member (servantId == uid() and status in ['PRESENT', 'ABSENT', 'ISSUE']).
      // Update: Only the servant who recorded it OR the Group Admin (الأمين فقط يعدّل تسجيل خادم تاني).
      // Delete: Group Admin can delete any record, and a Servant can delete their own record for Undo.
      match /attendance/{attendanceId} {
        allow get, list: if isSignedIn() && (
          ('memberUids' in existing() && uid() in existing().memberUids) ||
          isGroupMember(groupId)
        );
        allow create: if isGroupMember(groupId) &&
          incoming().servantId == uid() &&
          isValidAttendanceRecord(incoming(), groupId, attendanceId);
        allow update: if isGroupMember(groupId) &&
          incoming().servantId == uid() &&
          isValidAttendanceRecord(incoming(), groupId, attendanceId) &&
          incoming().studentId == existing().studentId &&
          incoming().weekKey == existing().weekKey &&
          (existing().servantId == uid() || isGroupAdmin(groupId));
        allow delete: if isGroupAdmin(groupId) ||
          (isGroupMember(groupId) && existing().servantId == uid());
      }

      // 2k. Shared Child Notes (Comments, Memorization progress, Visitation follow-ups)
      match /childNotes/{noteId} {
        allow get, list: if isSignedIn() && (
          ('memberUids' in existing() && uid() in existing().memberUids) ||
          isGroupMember(groupId)
        );
        allow create: if isGroupMember(groupId) && isValidChildNote(incoming(), groupId);
        allow update: if (
            isGroupAdmin(groupId) ||
            (isGroupMember(groupId) && existing().authorUid == uid())
          ) &&
          isValidChildNote(incoming(), groupId) &&
          incoming().groupId == existing().groupId &&
          incoming().studentId == existing().studentId &&
          incoming().authorUid == existing().authorUid &&
          incoming().createdAt == existing().createdAt;
        allow delete: if isGroupAdmin(groupId) ||
          (isGroupMember(groupId) && existing().authorUid == uid());
      }
    }

    // 3. Private Direct Message Rooms (dms/{chatId} where chatId = dm_{uidA}_{uidB} sorted)
    // Authorized via deterministic path `uid() in chatId.split('_')` or `participants` array without `get()`.
    match /dms/{chatId} {
      allow get: if isSignedIn() && (
        resource == null ||
        (uid() in chatId.split('_')) ||
        ('participants' in existing() && uid() in existing().participants)
      );
      allow list: if isSignedIn() && uid() in existing().participants;
      allow create: if isSignedIn() && isValidDmChatMeta(incoming(), chatId);
      allow update: if isSignedIn() &&
        (
          (uid() in chatId.split('_')) ||
          ('participants' in existing() && uid() in existing().participants)
        ) &&
        (!('participants' in existing()) || incoming().participants == existing().participants) &&
        isValidDmChatMeta(incoming(), chatId);
      allow delete: if false;

      match /messages/{messageId} {
        allow get, list: if isSignedIn() && (
          (uid() in chatId.split('_')) ||
          ('participants' in existing() && uid() in existing().participants)
        );
        allow create: if isSignedIn() && isValidDmChatMessageCreate(incoming(), chatId);
        allow update: if isSignedIn() &&
          (
            (uid() in chatId.split('_')) ||
            ('participants' in existing() && uid() in existing().participants)
          ) &&
          isValidChatMessageSoftDelete(incoming(), existing());
        allow delete: if false;
      }
    }
  }
}

- لا يوجد أي استخدام لـ Gemini API أو أي نموذج ذكاء اصطناعي في التطبيق (ملف .env.example يحتوي # GEMINI_API_KEY معلّقاً فقط وغير مستخدم).
- لا يوجد استخدام لـ Firebase Storage: جميع الصور (صور الأطفال/الخدام/الجروب/الشات) والرسائل الصوتية تُضغط وتُخزن كـ Base64 داخل مستندات Firestore للعمل مجاناً على خطة Spark.
- الخدمات المستخدمة فعلياً:
  1. Firebase Authentication & Cloud Firestore — الإعدادات موجودة في app/google-services.json و app/src/main/res/values/firebase_applet_config.xml (على الويب تُوضع قيم firebaseConfig في .env بـ VITE_FIREBASE_*).
  2. روابط WhatsApp و الهاتف: روابط مباشرة من المتصفح https://wa.me/<digits> و tel:<internationalPhone> بدون أي API key.
  3. (خاص بالأندرويد فقط ولا يُنقل للويب): GitHubSmartSyncEngine كان يفحص JSON من GitHub Releases لتحديث ملف APK — غير مطلوب في تطبيق الويب.

9. المنطق الخاص والقواعد الحرجة (يجب تنفيذها بنفس الشكل تماماً)
--------------------------------------------------------------------
1. تقويم أسابيع السبت + التقويم القبطي (SaturdayCalendarHelper):
   - يبدأ كل أسبوع جديد داخل الشهر يوم 1 من الشهر ثم عند كل يوم سبت الساعة 12:00 منتصف الليل.
   - صيغة مفتاح الشهر: YYYY-MM (مثل 2026-11).
   - صيغة مفتاح الأسبوع: YYYY-MM-W# (مثل 2026-11-W3).
   - تحويل التاريخ الميلادي إلى قبطي (تقويم الشهداء) يتم فلكياً عبر Julian Day Number (بداية العصر القبطي JDN = 1825030 = 1 توت سنة 1 للشهداء = 29 أغسطس 284م يولياني)، مع الشهور القبطية الـ 13 (توت حتى النسيء).

2. معرّفات الوثائق الحتمية (Deterministic Document IDs):
   - groups/{inviteCode} (حيث inviteCode == groupId).
   - groups/{groupId}/attendance/{weekKey}_{studentId} (مفروض بصرامة في الـ Rules).
   - groups/{groupId}/monthlyBalances/{monthKey}_{studentId}.
   - groups/{groupId}/avatars/{studentId}.
   - groups/{groupId}/members/{uid}.
   - groups/{groupId}/chatMeta/main.
   - dms/dm_{sortedUidA}_{sortedUidB}.
   - emailDirectory/em_{sha256Hex(normalizedEmail).slice(0, 40)}.

3. قواعد منح الكروت وتحديث الرصيد الشهري الذري:
   - عند منح كارت: التحقق من enforceWeeklyCardLimit (لا يتكرر نفس الكارت لنفس الطفل في نفس weekKey)، ومن maxMonthlyPoints، ومن تكرار CUSTOM_ELDER (WEEKLY / MONTHLY / ONCE_EVER).
   - عند إضافة أو حذف cardEvent يجب تحديث monthlyBalances/{monthKey}_{studentId} في نفس العملية (totalPoints, eventsCount, lastUpdatedByUid) بحيث لا تنزل القيم تحت 0.

4. صيغ رسائل التقارير المتبادلة مع تطبيق الموبايل (Wire Formats):
   أ) تقرير التحضير والكروت [ATTENDANCE_V3]:
      [ATTENDANCE_V3]
      S|<اسم الخادم>
      T|<ATTENDANCE_ONLY أو cardType.id>
      TL|<عنوان التقرير مثل: تقرير الحضور أو تقرير كارت الهدوء>
      IC|<أيقونة مثل 📋 أو 🤫>
      CK|<مفتاح اللون مثل EMERALD أو SKY>
      PL|<اسم حاضر1 • اسم حاضر2 • ...>
      A|<studentId>|<studentNumber>|<studentName>
      N|<studentId>|<studentNumber>|<studentName>|<cardTitle>
      I|<studentId>|<studentNumber>|<studentName>|<ملاحظة المشكلة>

      وعند وجود اختلافات ضد خادم سابق، يُضاف سطر DIFF|<اسم الخادم الأول> وأسطر:
      D|<studentId>|<studentNumber>|<studentName>|<حالة الخادم الأول>|<حالة الخادم الثاني>|<ملاحظة اختيارية>

   ب) تقرير الافتقاد المجمع المتحدث لحظياً [VISITATION_V1]:
      [VISITATION_V1]
      S|<اسم الخادم>
      B|<اسم البلوك أو كل الفصل>
      V|<studentId>|<studentNumber>|<studentName>
      F|<studentId>|<studentNumber>|<studentName>|<ملاحظة المتابعة>
      U|<studentId>|<studentNumber>|<studentName>

      (تحديث هذه الرسالة يتم بـ updateDoc على الحقلين text و updatedAt فقط لتوافق isValidLiveSystemReportUpdate!)

   - يجب أن يدعم عارض الرسائل في الويب تحليل [VISITATION_V1] و [ATTENDANCE_V3] (و [ATTENDANCE_V2] القديم) حتى تظهر رسائل الموبايل والويب بنفس الشكل الجمالي المتطابق.

5. صور الأطفال المتعددة (Packed Avatar Format):
   - يمكن أن يحتوي avatarBase64 في avatars/{studentId} على صورة واحدة (Base64 خام بدون prefix data:image/...) أو عدة صور مفصولة بالفاصل ||| (الصورة الأولى هي الأساسية). عند العرض أضف data:image/jpeg;base64, إذا لم يبدأ بـ data:. الحد الأقصى للنص 360000 حرف.

6. الترتيب الكسري للأطفال (Fractional Positioning):
   - ترتيب الطفل الفعلي = position != 0 ? position : (sortOrder * 1000 + studentNumber). عند السحب وإعادة الترتيب بين طفلين يتم حساب المتوسط (prev + next) / 2 لتحديث مستند واحد فقط دون إعادة ترقيم الباقي.

7. كود الدعوة اليومي:
   - الصيغة <inviteCode>-<dailyToken>؛ مدة الصلاحية 24 ساعة من inviteCodeUpdatedAtMillis.
   - دالة التحليل parseInviteCodeInput: تزيل المسافات وتحول لـ Uppercase وتفصل عند - (وإذا كُتب بدون - وكان يبدأ بـ KAM وطوله > 8، أول 8 أحرف هي inviteCode والباقي dailyToken).

8. حقول إلزامية دقيقة في الـ Rules:
   - في members/{uid} يجب أن يكون phoneVerified: false دائماً وإلا سترفض Firestore الكتابة.
   - في chatMeta/main و messages/{id} و attendance/{id} يجب تمرير memberUids (وتضم auth.uid).
   - في الحذف الناعم لرسائل الشات يجب أن يكون text: "تم حذف الرسالة" بالحرف و isDeleted: true و mediaBase64: "".
