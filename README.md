## رابط التطبيق المباشر على GitHub Pages

## ملاحظة Firebase لتسجيل الدخول بجوجل
لتشغيل تسجيل الدخول بحساب Google على الرابط الجديد، تأكد من إضافة الدومين `kett45.github.io` (بدون `https://` وبدون `/Wap`) في:
`Firebase Console → Authentication → Settings → Authorized domains`
