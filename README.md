  `https://<username>.github.io/<repo-name>/`

## تفعيل GitHub Pages لأول مرة (لو ظهر خطأ ❌ في Actions)
1. تأكد أن الريبو **Public** من: `Settings → General → Danger Zone → Change repository visibility → Make public`.
2. من `Settings → Pages` تحت **Build and deployment** اختر **Source: GitHub Actions**.
3. اضغط **Re-run all jobs** في تبويب **Actions** وسيتم النشر وتحديث رابط الموقع في وصف الريبو تلقائيًا.
